# TimingDiagram

An editor for timing diagrams that runs in the web browser on Linux and Windows.

- Channels stacked vertically on one shared time axis
- Transition points you can drag, or type to an exact time
- A value per point and channel, each either a step or a gradual ramp
  (digital and analog signals in one diagram)
- Export to Excel, PDF and HTML

**Status:** in development. See the [plan](docs/PLAN.md).
