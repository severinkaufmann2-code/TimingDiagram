Click the marker lane to add a transition point Drag a marker to move it, click it to type an exact time Drag a dot to change a value, click it to type one and choose Step or Ramp

Channels

“Add channel” puts a new lane at the bottom. Click a name to rename it. The bin removes the lane and Undo brings it back. Drag the grip to reorder.

Transition points

Click the marker lane of the ruler to add one. Drag a marker sideways and every channel follows. Click a marker to type the exact time.

Values

Where a point crosses a channel you can set a value: drag the dot up or down, or click it and type. Step holds the previous value, then jumps. Ramp rises or falls gradually from the previous point.

Export

Excel (.xlsx), PDF and a standalone web page (.html) from the Export menu. Save keeps an editable project file.
